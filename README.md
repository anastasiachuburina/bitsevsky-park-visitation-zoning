# Исследование потенциальной посещаемости Битцевского парка

## Описание проекта

Проект посвящен исследованию территории Битцевского парка по предполагаемой интенсивности посещаемости. В работе учитывались пространственные факторы, которые могут влиять на распределение посетителей: дорожная сеть, входы в парк, объекты досуга и туризма, барьеры, тип открытости пространства и особенности рельефа.

Результатом проекта стала карта зонирования территории парка, отражающая различия в потенциальной посещаемости отдельных участков.

## Цель проекта

Цель проекта — построить карту потенциальной интенсивности посещаемости Битцевского парка на основе пространственного анализа факторов, влияющих на перемещение и концентрацию посетителей.

## Задачи

В рамках проекта были выполнены следующие задачи:

- подготовка и обрезка исходных пространственных данных по границе парка;
- анализ дорожной сети и разделение дорог по типу покрытия;
- расчет плотности дорог, объектов досуга, объектов туризма и барьеров;
- оценка потенциального посетительского потока от входов в парк;
- учет типа пространства: лесные и открытые участки;
- учет рельефа на основе индекса TPI;
- нормализация факторов к единой шкале;
- расчет итогового индекса посещаемости методом взвешенного суммирования;
- подготовка итоговой карты зонирования.

## Использованные данные

В проекте использовались следующие пространственные данные:

- граница исследуемой территории;
- дорожная сеть OpenStreetMap;
- точки входов в парк;
- объекты досуга;
- объекты туризма;
- барьерные объекты;
- данные о залесенности и открытых пространствах;
- растровые данные населения WorldPop;
- цифровая модель рельефа AW3D.

Основные пространственные данные и производные растры размещены в файловой геобазе в папке `data/`.

## Методы

Основной метод проекта — многокритериальный пространственный анализ с использованием растровых слоев и взвешенного суммирования.

Для отдельных факторов применялись следующие методы:

- `Clip` — обрезка данных по границе парка;
- `Line Density` — расчет плотности дорожной сети;
- `Kernel Density` — расчет плотности объектов досуга, туризма, барьеров и входов;
- `Buffer` — построение зон вокруг входов в парк;
- `Zonal Statistics as Table` — расчет численности населения в пределах буферов входов;
- `Polygon to Raster` — перевод данных о залесенности в растровый формат;
- `Reclassify` — приведение факторов к единой шкале;
- `Weighted Sum` — расчет итогового индекса потенциальной посещаемости.

Итоговый индекс был рассчитан с учетом положительных и отрицательных факторов: дорожной сети, входов, объектов досуга и туризма, открытости пространства, барьеров и рельефа.

## Структура репозитория

- `data/` — файловая геобаза с основными пространственными данными и производными растровыми слоями, описание использованных данных;
- `outputs/` — итоговые карты и карты отдельных факторов в формате PNG;
- `metadata/` — метаданные проекта;
- `report/` — практическая работа с описанием данных, методов, расчетов и выводов.

## Основные результаты

По результатам анализа были выделены зоны с различной предполагаемой интенсивностью посещаемости. Наиболее высокая посещаемость ожидается вблизи входов в парк, участков с развитой дорожной сетью и рядом с объектами досуга и туризма.

Менее посещаемыми являются удаленные, труднодоступные и более закрытые лесные участки, а также территории, где присутствуют барьеры для перемещения.

Полученная карта может использоваться для предварительной оценки рекреационной нагрузки, планирования маршрутов, размещения инфраструктуры и анализа пространственной организации городской природной территории.

## Авторский вклад

Проект выполнен в рамках командной практической работы по дисциплине «Статистические методы пространственного анализа».

В составе команды автор участвовала в подготовке пространственных данных для анализа: выгрузке и обработке данных OpenStreetMap через QuickOSM, работе с дорожной сетью, объектами досуга и туризма, входами в парк, барьерами, данными о залесенности, растровыми данными WorldPop и цифровой моделью рельефа AW3D.

Также в рамках командной работы была выполнена предобработка данных и создание рабочей базы для анализа: обрезка слоев по границе исследуемой территории, приведение растров к единому размеру ячейки 100 м, разделение дорожной сети на асфальтированные дороги и тропинки без специального покрытия.
Индивидуальный вклад автора включал учет рельефа через расчет и интерпретацию индекса TPI, преобразование TPI в показатель удобства территории, нормализацию факторов к единой шкале и расчет итогового индекса потенциальной посещаемости методом взвешенного суммирования `Weighted Sum`.
Автором также выполнены интерпретация итоговой карты зонирования, описание методики и формулировка выводов по результатам проекта.
